# 配色、画幅与偏好

## 一次简短选择

有已确认品牌色或项目风格就沿用；首次没有偏好时展示[配色预览](../assets/palette-preview.html)，或直接列出下表，问喜欢哪几个色系，可多选或请助手推荐。

| 编号 | 色系 | 主要感觉 | 常见适用内容 |
|---|---|---|---|
| P1 | 电光蓝紫 | 深底、清楚、有科技感 | 工具测评、软件演示 |
| P2 | 青绿青柠 | 深绿底、清新、重点鲜明 | AI工作流、效率教程 |
| P3 | 奶油珊瑚 | 浅底、温暖、轻杂志 | 方法讲解、创意分享 |
| P4 | 暖白琥珀 | 浅底、亲切、对比清晰 | 入门教程、日常应用 |
| P5 | 淡紫莓色 | 浅底、柔和、有创意感 | AI作图、视频玩法 |
| P6 | 黑白朱红 | 克制、重点明确 | 对比评测、知识讲解 |

颜色的HEX与用途以[色板数据](../assets/palettes.json)为准。多选后确定一个主色板，另一组只借少量辅助色；正文、背景和强调色分清角色。用户给自定义HEX时照其意愿适配可读性。

不知道选什么：软件演示推荐P1、备选P6；生活化知识推荐P3、备选P4；视觉创作推荐P5、备选P2。这是建议，不能把推荐自动当用户已选。

不把用户称赞参考动效解释为接受参考配色。严格参考与用户主题色冲突时，只问保留原色还是替换为个人主题色，并在参考差异中记录。常规模式用户已经明确选色，就直接用；用户说“你定”可以采用推荐并说明。

## 默认沿用口播尺寸

读取主口播真实显示宽高、旋转方向和帧率。通常沿用其画幅、像素尺寸与帧率创建时间线；不能把参考视频的横屏／竖屏、课程平台习惯或默认新项目尺寸当作主片尺寸。

例如：主口播显示1080×1920、参考是1920×1080，成片仍以1080×1920构图。动作语言可以借鉴，横屏坐标要重新布局。用户明确要求改画幅时说明人物与录屏如何裁切或留边，再执行，不拉伸变形。

本地原片可用：

```text
python "本Skill实际安装目录/scripts/probe_media.py" "主口播的实际路径.mp4"
```

先把示例中的安装目录与素材路径替换成实际值。脚本只读探测，不假定用户素材文件夹里存在scripts。它需要ffprobe；ChatCut已返回可靠显示尺寸时直接使用，不强迫用户额外安装。编码宽高不等于旋转后的显示尺寸；遇非方形像素、旋转或多段画幅冲突，结合实际源帧核对后决定。

## 构图与字幕

- 先确定落稳画面，再设计入场。短边约5%—8%的边距可作试排起点，最终看实际画面、人物和操作区域。
- 普通口播尽量保留人物；演示段按内容使用人物小窗或全屏素材，不强制每帧固定右上人物框。用户要求人物全程可见时才执行全程覆盖。
- 录屏要能看清关键操作，优先保留原有缩放，再补必要的局部聚焦。不要为放大而丢掉结果、工具名称或按钮。
- 默认清楚的中文无衬线字体，以当前云端可用字体为准；代码或参数可用等宽字。不能声称字体匹配而实际未加载。
- 常规字幕按完整短句分组，优先单行；竖屏或长句按可读性允许两行，不能继承私人规范的绝对单行限制。避免三五字机械闪动，也不把整段长句挤到屏幕上。
- 字幕不遮嘴、脸、重要按钮和结果；动效大字只保留重点，不和逐字字幕争抢全部区域。

## 保存范围

将当前项目的模式、画幅来源、色板、字体、字幕和声音选择写入制作目录的`剪辑偏好.json`，参照[偏好示例](../assets/preferences.example.json)。未知字段保持空值，完成实际读取再填写；不把示例数值当用户素材事实。

偏好只包含剪辑选择和实际项目／素材引用，不包含令牌、密码、作者私有路径或其他账号资料。用户修改其中一项时只调整相关部分，其他项目不自动改色或改画幅。
