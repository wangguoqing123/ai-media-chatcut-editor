# 常规模式：没有参考时怎样剪

已有风格和主题色就沿用。没有参考、也没有明确风格时，按内容推荐下表的一种；用户说“你决定”即可采用推荐并说明，不再跑一遍品牌定位访谈。

| 风格 | 适合 | 主要编排 | 动作与声音 |
|---|---|---|---|
| 工具演示 | 软件教程、工具测评 | 真实结果开场，录屏与关键步骤为主，人物按需要出现 | 名称亮相归位、按钮聚焦、局部放大、输入到结果；关键点击用轻click，步骤完成用轻提示 |
| 清爽知识 | 概念、方法、工具清单 | 口播为主，关键词、清单、对比辅助解释 | 标题遮罩揭示、清单错峰、对比原位替换、流程逐步连接；只在内容节点点声 |
| 作品展示 | AI图片／视频效果、提示词玩法 | 先给自己的结果，再给前后差异与关键做法 | 成品全屏、对比滑动或分屏、细节推近、步骤说明；画面需要安静时减少文字和声音 |
| 轻杂志 | 创意分享、案例讲解 | 大小字级、明确留白、图文关系清楚 | 小幅上浮、窗口展开、柔和遮罩与章节标签；少量纸感／轻提示声，BGM保持低存在感 |

风格与颜色是两件事。以上都可以用用户已选色板，不把“科技感”固定成某一种青柠，不把“轻杂志”固定成必须奶油色。

## 内容驱动的动作

先逐段判断观众需要看懂什么，再从[motion-library.md](motion-library.md)选动作。没有新视觉信息的段落可以保持口播，不为凑动效密度加空框、乱飞图标或无意义推拉。

常规入场可从0.25—0.55秒辅助标签、0.6—1.0秒主要图形开始试，短边1%—7%的位移配合缓出；列表错峰可先试0.15—0.28秒。它们是适配起点，不是强制时钟，实际讲述、帧率、信息量和用户节奏优先。

先把内容全部落稳的画面排清楚，再设计入场、阅读、让位和退出。主要文字落稳后保持稳定；下一项没讲到就真正隐藏，不能提前暴露终态、空占位或悬空连线。

## 人物与真实素材

普通口播段保留人物表达，操作和结果段用真实录屏／效果素材承接。是否保留小窗跟随用户要求与画面可用区域，不继承固定右上、固定横屏的私人模板。

点名工具时让名称完整出现、读得清，再连续缩小归位，给演示让空间。不要让大字消失后小字突然跳现。长名称按实际长度排版，避免撞人物、字幕和按钮。

录屏先看源片首帧、已有缩放和完整操作。保留有意义的原生动作，再补必要的按钮／结果聚焦；不把原操作裁成静帧，不为了稳画面切掉关键步骤。模拟图形明确标“示意”，不伪造真实界面、Logo、数据或亲测结果。

## 声音与字幕

人声优先。普通BGM选择低占用、节奏稳定的音乐床，用户不想要就不加；已有BGM符合要求时继续用，不顺手换曲。需要选择时先用当前可用库和用户素材，实际试听后决定。

关键点击、入场落稳、完成和章节转场可以有对应音效，适量且类别统一。不要每个字、每次切镜都加声。音量以真实口播和试听为准，不继承私人固定增益、固定增强或全片1.1倍速。

字幕从稳定后的语音生成，按语义分句，名称与数字核对。主题色只强调必要关键词，保证完整阅读时间和安全区；不把讲解里所有词都做成抢眼动画。

## 一条完整视频的工作顺序

清理口播 → 定逐段内容与素材 → 应用主题色和字体 → 制作同类MG与关键素材效果 → 添加并混合音效／BGM → 刷新字幕同步 → 实际画面和声音验收 → 交付可编辑工程及用户要求的导出。

这是依赖顺序，不是每一步都要停下来让用户批准。方向已经确定且用户授权整条制作时连续完成；局部修改只检查受影响范围。
