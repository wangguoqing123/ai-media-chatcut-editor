# 内置场景与动作库

从现有ChatCut云端剪辑规范提炼，已移除私人横屏坐标、固定人物框、品牌和项目素材ID。按当前内容选择少量一致动作；工具是否支持、参数如何写，以实际Hosted playbook与schema为准。

| 语义场景 | 可用动作 | 真实内容与声音落点 |
|---|---|---|
| 工具／产品亮相 | 名称或真实图标轻缩放入场，认清后连续移动缩小归位 | 说到名称时开始，落稳可用轻pop／click；后续留足实际操作时间 |
| 数量与工具合集 | 数字递增到真实数量后停稳，名称按讲述依次出现 | 不预填没提供的数量；最后留整体阅读时间 |
| 标题与章节 | 遮罩揭示、短位移缓出，编号／线条／标题依次展开 | 章节切换才用统一转场声，不把每次切镜当章节 |
| 操作步骤 | 每讲一步再显示一步，已显示项稳定保留 | 箭头在线索和目标都出现后再连，音效对准实际点击／完成 |
| 前后对照 | 原位替换、左右／上下对比、局部推近 | 两侧是真实可比较的结果，保证名称与差异看得清 |
| 查询与资料来源 | 输入、摘要、原链接依次出现 | 用实际检索结果和来源，不造新闻与引用 |
| 材料汇聚成结果 | 节点先出现，再沿路径汇聚、收拢和组装 | 动作表达真正发生的变化，完成时才给完成声 |
| 转写或提取 | 波形到文本、原文到重点的连续变化 | 使用自己的内容，保留可读结果，不只闪一个抽象标签 |
| 软件录屏 | 保留原生缩放，必要时局部聚焦按钮或结果 | 不截掉首帧有效动作，不双重叠加相反缩放 |
| 提示词／参数 | 文字分层、关键段高亮、输入到结果 | 正文稳定，不让长提示词持续漂移；需要阅读就多留时间 |
| 作品集合 | 真实作品先展示，再收拢到总结 | 不用假结果填空，重要作品有辨认时间 |
| 结尾总结 | 关键词或图标级联收束，回到人物或结果 | 结束前清掉辅助层和尾音，不再引入新知识 |

## 基础出退场

- **方向滑入：**位移逐渐减速，按需要加透明度；退出加速离开，方向与下一画面有关系。
- **遮罩揭示：**在固定区域内逐行或横向露出，适合标题和标签；退场反向收回。
- **轻缩放弹入：**图标从较小到正常，轻微过冲后落稳；不让所有正文一直弹跳。
- **上浮落位：**小位移、透明到清晰，适合窗口与说明；停稳后保证阅读。
- **错峰级联：**按实际口播逐项显示；未讲项连框线也隐藏，不出现终态闪回。
- **原位替换：**旧内容退出、新内容在同一视觉位置进入，适合状态或工具对比。
- **描边与聚焦：**围绕真实按钮／区域绘制框、圈、箭头，目标出现后再画线。
- **窗口展开：**概览中的窗口连续放大到演示，不先退出留空再硬切。

粒子、故障、RGB、强闪白、复杂人物遮挡等只在内容或参考确实需要、当前工具可实现且可验收时使用。不能把不会做的遮挡用盖住人脸冒充。

## 同步原则

每段记录实际开始、落位、阅读结束和退出位置。把秒换算为当前项目帧率，不复用旧工程的固定帧数。SFX峰值对准真正落稳、点击或切换瞬间，考虑音频自身前奏。

字幕、人物、工具名、主视觉和按钮分别留可用区域。同一时刻只有一个主要信息焦点；信息多时减少运动，必要文字完整可读。镜头、素材与字幕层不能因为统一效果而覆盖彼此。
